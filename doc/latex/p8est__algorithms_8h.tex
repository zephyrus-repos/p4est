Compute correction of partition for a process. 

The correction denotes how many quadrants the process with id {\itshape rank} takes from (if correction positive) or gives to (if correction negative) the previous process with id {\itshape rank-\/1} in order to assign a family of quadrants to one process. The process with the highest number of quadrants of a family gets all quadrants belonging to this family from other processes. If this applies to several processes, then the process with the lowest id gets the quadrants. A process can give more quadrants than it owns, if it passes quadrants from other processes.
