The \mbox{\hyperlink{structp4est}{p4est}} library comes with various example programs.

They are kept under the subdirectory \href{https://github.com/cburstedde/p4est/tree/master/example}{\texttt{ example}}. Most have both a 2D and a 3D version. When the library is configured {\ttfamily -\/-\/enable-\/mpi}, they can all be run in parallel on any number of MPI ranks, even on small computers.

One first helpful program to try out is called {\ttfamily p4est\+\_\+simple} (2D version) and {\ttfamily p8est\+\_\+simple} (3D version), both under \href{https://github.com/cburstedde/p4est/tree/master/example/simple}{\texttt{ simple}}. We showcase some 2D results further below on this page, and we encourage everyone to play with the command line arguments.\hypertarget{example_simple2_autotoc_md15}{}\doxysubsubsection{The first step example}\label{example_simple2_autotoc_md15}
Quite some time later, we created a range of step-\/by-\/step examples under \href{https://github.com/cburstedde/p4est/tree/master/example/steps}{\texttt{ steps}}. Let us begin here with the first one that generates a mesh spelling \textquotesingle{}Hello, World!\textquotesingle{}\+: \mbox{\hyperlink{steps_2p4est_step1_8c-example}{steps/p4est\+\_\+step1.\+c}}.

This program performs refinement on a simple domain based on hardcoded image data. As a result, the output VTK file displays the phrase \textquotesingle{}Hello World\textquotesingle{} by the mesh refinement.

Usage may be one of\+:

\begin{quote}
{\ttfamily p4est\+\_\+step1} \end{quote}
or with MPI\+: \begin{quote}
{\ttfamily mpirun -\/np 3 p4est\+\_\+step1} \end{quote}

\begin{DoxyItemize}
\item No. of trees\+: 1
\item Maximum refinement level\+: 6


\end{DoxyItemize}\hypertarget{example_simple2_autotoc_md16}{}\doxysubsubsection{The historic simple example}\label{example_simple2_autotoc_md16}
Another illustrative example can be found in \mbox{\hyperlink{simple_2simple2_8c-example}{simple/simple2.\+c}}. The refinement pattern is generated by some hardcoded prescriptions based on a quadrant\textquotesingle{}s tree number, refinement level and coordinates. Please see the documentation under that link for a full list of configurations.

This program creates/refines \& coarsens/balances/partitions one of several available geometries specified on the command line. As a result, the output VTK files document all the steps of the mesh manipulation process.


\begin{DoxyItemize}
\item Example\+: periodic

Create a connectivity structure for a periodic unit square. The left and right faces are identified, and bottom and top opposite.

Usage\+: \begin{quote}
{\ttfamily p4est\+\_\+simple periodic 5} \end{quote}
or with MPI\+: \begin{quote}
{\ttfamily mpirun -\/np 4 p4est\+\_\+simple periodic 5} \end{quote}

\begin{DoxyItemize}
\item No. of trees\+: 1
\item Maximum refinement level\+: chosen on the command line as 5
\end{DoxyItemize}
\end{DoxyItemize}




\begin{DoxyItemize}
\item Example\+: circle

Create a connectivity structure for an donut-\/like circle. The circle consists of 6 trees connecting each other by their faces. The trees are laid out as a hexagon between $[-2, 2]$ in the y direction and $[-\sqrt{3}, \sqrt{3}]$ in the x direction. The hexagon has flat sides along the y direction and pointy ends in x.

Usage\+: \begin{quote}
{\ttfamily p4est\+\_\+simple circle 5} \end{quote}
or with MPI\+: \begin{quote}
{\ttfamily mpirun -\/np 4 p4est\+\_\+simple circle 5} \end{quote}

\begin{DoxyItemize}
\item No. of trees\+: 6
\item Maximum refinement level\+: chosen on the command line as 5
\end{DoxyItemize}
\end{DoxyItemize}
