\doxysubsection{Detailed Description}
This wrapper API encapsulates core \mbox{\hyperlink{structp4est}{p4est}} data structures and provides functions that clarify the mark-\/adapt-\/partition cycle. 

There is also an element iterator that can replace the nested loops over trees and tree quadrants, respectively, which can help make application code cleaner.

For most new code, using this API is likely not necessary.
