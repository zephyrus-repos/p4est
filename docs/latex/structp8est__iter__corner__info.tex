\doxysubsection{Detailed Description}
The information that is available to the user-\/defined p8est\+\_\+iter\+\_\+corner\+\_\+t callback. 

If tree\+\_\+boundary is false, the corner is on the interior of a tree. When tree\+\_\+boundary is false, sides\mbox{[}0\mbox{]} contains the lowest z-\/order quadrant that touches the corner. When tree\+\_\+boundary is true, its value is P8\+EST\+\_\+\+CONNECT\+\_\+\+FACE/\+EDGE/\+CORNER depending on the location of the corner relative to the tree.
