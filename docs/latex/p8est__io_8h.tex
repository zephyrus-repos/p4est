\doxysubsection{Detailed Description}
Provide functions to serialize/deserialize a forest. 

Some are used as building blocks for \mbox{\hyperlink{p8est_8h_a617eaa5b07df457803ba449cb8ad1373}{p8est\+\_\+load}} and \mbox{\hyperlink{p8est_8h_aa085d8890ad0c5cd2cf1b34acf5e12c6}{p8est\+\_\+save}}. Others allow for saving and loading user-\/defined data to a parallel file.

Furthermore, this module provides functions to write and read general data files associated with a \mbox{\hyperlink{structp8est}{p8est}}.

However, you can not read and write external mesh associated data using a \mbox{\hyperlink{structp8est}{p8est}} function if you do not use the p4est\+\_\+file functions. If you still want to use the p8est\+\_\+file functions you can configure with --enable-\/file-\/deprecated or use the variable enable-\/file-\/deprecated in CMake.
