\doxysubsection{Detailed Description}
Union for quadrant data. 

It is important to notice that \mbox{\hyperlink{unionp4est__quadrant_1_1p4est__quadrant__data_a39ddcaeb28e32c084953512cd04c1c9f}{piggy1}} and \mbox{\hyperlink{unionp4est__quadrant_1_1p4est__quadrant__data_a5513a4e73d441fa4bbf5797fc7eb57df}{piggy2}} are only used internally. Hence, they are not part of the API.

Usually \mbox{\hyperlink{unionp4est__quadrant_1_1p4est__quadrant__data_ac515f7cf5f7e1ba9772ee185f3ad98f0}{piggy3}} is also not part of the API. The only exception holds for quadrants in the \mbox{\hyperlink{structp4est__ghost_a06a0c2dfa2f05929d58ed85f0117228c}{ghosts}} array of p4est\+\_\+ghost\+\_\+t (cf. documentation of \mbox{\hyperlink{structp4est__ghost_a06a0c2dfa2f05929d58ed85f0117228c}{ghosts}}).
