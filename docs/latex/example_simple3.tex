The \mbox{\hyperlink{structp4est}{p4est}} library comes with various example programs.

They are kept under the subdirectory \href{https://github.com/cburstedde/p4est/tree/master/example}{\texttt{ example}}. Most have both a 2D and a 3D version. When the library is configured {\ttfamily -\/-\/enable-\/mpi}, they can all be run in parallel on any number of MPI ranks, even on small computers.

Before proceeding with the examples on this page, it is highly recommended to get familiar with the programs, starting from 2D examples in \mbox{\hyperlink{example_simple2}{Documentation for selected 2D example programs}}.

One first helpful program to try out is called {\ttfamily p4est\+\_\+simple} (2D version) and {\ttfamily p8est\+\_\+simple} (3D version), both under \href{https://github.com/cburstedde/p4est/tree/master/example/simple}{\texttt{ simple}}. On this page, we showcase some results of 3D example programs further below on this page, and we encourage everyone to play with the command line arguments.\hypertarget{example_simple3_autotoc_md17}{}\doxysubsubsection{The historic simple example}\label{example_simple3_autotoc_md17}
The example can be found in \mbox{\hyperlink{simple_2simple3_8c-example}{simple/simple3.\+c}}. It is a 3D version of \mbox{\hyperlink{simple_2simple2_8c-example}{simple/simple2.\+c}} The refinement pattern is generated by some hardcoded prescriptions based on a octants\textquotesingle{}s tree number, refinement level and coordinates. Please see the documentation under the link for a full list of configurations.

This program creates/refines \& coarsens/balances/partitions one of several available geometries specified on the command line. As a result, the output VTK files document all the steps of the mesh manipulation process.

\item Example\+: unit

Create a connectivity structure for a stand-\/alone unit cube.

Usage\+: \begin{quote}
{\ttfamily p8est\+\_\+simple unit 5} \end{quote}
or with MPI\+: \begin{quote}
{\ttfamily mpirun -\/np 4 p8est\+\_\+simple unit 5} \end{quote}

\begin{DoxyItemize}
\item No. of trees\+: 1
\item Maximum refinement level\+: chosen on the command line as 5
\end{DoxyItemize}
\end{DoxyItemize}
