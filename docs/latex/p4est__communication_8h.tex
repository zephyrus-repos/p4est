Transfer data associated with one forest partition to another. 

In \mbox{\hyperlink{p4est_8h_a54c1f4e6bc35c181952371a8046523aa}{p4est\+\_\+partition}}, each quadrant\textquotesingle{}s user data is transferred. If the application maintains per-\/quadrant data outside of the \mbox{\hyperlink{structp4est}{p4est}} object, this function can be used to transfer it, matching the call to partition. This variant of the function assumes that the quadrant data size is fixed. It sends point-\/to-\/point messages only and is blocking collective. There is a split collective version; see the functions \mbox{\hyperlink{p4est__communication_8h_ac6cf04f77acd2255d8a4037cfab22bf2}{p4est\+\_\+transfer\+\_\+fixed\+\_\+begin}} and \mbox{\hyperlink{p4est__communication_8h_a1ee45c44a755dc9ba14af20661d10bab}{p4est\+\_\+transfer\+\_\+fixed\+\_\+end}}.

(See \mbox{\hyperlink{p4est__communication_8h_a9a9ef6c16f81067f0c917a838a8fdfac}{p4est\+\_\+transfer\+\_\+fixed}} that is optimized for fixed-\/count data, and \mbox{\hyperlink{p4est__communication_8h_ace044f4c221f25afbb9a198ff24b676a}{p4est\+\_\+transfer\+\_\+custom}} for data that is not itemized at all.)
