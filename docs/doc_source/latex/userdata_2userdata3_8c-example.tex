\hypertarget{userdata_2userdata3_8c-example}{}\doxysection{userdata/userdata3.\+c}
A 3D example of managing application data.\+The workflow is documented more extensively in \mbox{\hyperlink{example_userdata}{A demonstration of how to manage application data}}.

The 3D version of th this demo compiles from the same code as the 2D example \mbox{\hyperlink{userdata_2userdata2_8c-example}{userdata/userdata2.\+c}} with minimal redefinitions. In this sense, the code is mostly dimension independent.
