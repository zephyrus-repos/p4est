\doxysubsection{Detailed Description}
Forest topology in a conventional mesh format. 

A typical workflow starts with \mbox{\hyperlink{p8est__mesh_8h_a215274f453be642637ce4572cc9b126c}{p8est\+\_\+mesh\+\_\+params\+\_\+init}} to initialize a \mbox{\hyperlink{structp8est__mesh__params__t}{p8est\+\_\+mesh\+\_\+params\+\_\+t}}, followed by eventual user-\/dependent changes to the parameters.

Next a \mbox{\hyperlink{structp8est__mesh__t}{p8est\+\_\+mesh\+\_\+t}} is created with \mbox{\hyperlink{p8est__mesh_8h_adaa1defdb41a2510def4310bc85b97a2}{p8est\+\_\+mesh\+\_\+new\+\_\+params}}.

Now, the user can create a \mbox{\hyperlink{structp8est__mesh__face__neighbor__t}{p8est\+\_\+mesh\+\_\+face\+\_\+neighbor\+\_\+t}} with \mbox{\hyperlink{p8est__mesh_8h_a29e8d928609f4de7b57b3f42e8c1969d}{p8est\+\_\+mesh\+\_\+face\+\_\+neighbor\+\_\+init}} and loop over a quadrants face neighbors by repeated calls to \mbox{\hyperlink{p8est__mesh_8h_a55d6ff447a7e73a5c3855900b7408540}{p8est\+\_\+mesh\+\_\+face\+\_\+neighbor\+\_\+next}}.

Once done, the mesh has to be destroyed with \mbox{\hyperlink{p8est__mesh_8h_a21f8d0dc350550c5455f2175dfd5aaa0}{p8est\+\_\+mesh\+\_\+destroy}}.
