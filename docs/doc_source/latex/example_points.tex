The points example refines a domain according to a given set of points.

The points can be generated by calling the helper program \mbox{\hyperlink{points_2generate_points2_8c-example}{points/generate\+\_\+points2.\+c}} (2D) or \mbox{\hyperlink{points_2generate_points3_8c-example}{points/generate\+\_\+points3.\+c}} (3D). The point example itself resides in the source files for \href{https://github.com/cburstedde/p4est/blob/master/example/points/points2.c}{\texttt{ 2D}} and \href{https://github.com/cburstedde/p4est/blob/master/example/points/points3.c}{\texttt{ 3D}}.
