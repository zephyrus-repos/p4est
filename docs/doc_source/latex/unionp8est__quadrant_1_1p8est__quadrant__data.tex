\doxysubsection{Detailed Description}
Union for quadrant data. 

It is important to notice that \mbox{\hyperlink{unionp8est__quadrant_1_1p8est__quadrant__data_a54998361060406113deb266b727fef2c}{piggy1}} and \mbox{\hyperlink{unionp8est__quadrant_1_1p8est__quadrant__data_a6b5a89842696839a22d9d101cbe38663}{piggy2}} are only used internally. Hence, they are not part of the API.

Usually \mbox{\hyperlink{unionp8est__quadrant_1_1p8est__quadrant__data_a6af834339eec1c3d1f40c6cbe25ca51d}{piggy3}} is also not part of the API. The only exception holds for quadrants in the \mbox{\hyperlink{structp8est__ghost_ab82ceaa55368a07a928b9e15f78969c8}{ghosts}} array of p8est\+\_\+ghost\+\_\+t (cf. documentation of \mbox{\hyperlink{structp8est__ghost_ab82ceaa55368a07a928b9e15f78969c8}{ghosts}}).
