\doxysubsection{Detailed Description}
This structure contains complete mesh information on a 2\+:1 balanced forest. 

It stores the locally relevant neighborhood, that is, all locally owned quadrants and one layer of adjacent ghost quadrants and their owners.

For each local quadrant, its tree number is stored in quad\+\_\+to\+\_\+tree. The quad\+\_\+to\+\_\+tree array is NULL by default and can be enabled using \mbox{\hyperlink{p4est__extended_8h_a8e8ccb957397b2a568e8a86d29a6ce4a}{p4est\+\_\+mesh\+\_\+new\+\_\+ext}} or \mbox{\hyperlink{p4est__mesh_8h_a663b5101edeb5674d66a7c3692d6661a}{p4est\+\_\+mesh\+\_\+new\+\_\+params}}. For each ghost quadrant, its owner rank is stored in ghost\+\_\+to\+\_\+proc. For each level, an array of local quadrant numbers is stored in quad\+\_\+level. The quad\+\_\+level array is NULL by default and can be enabled using \mbox{\hyperlink{p4est__extended_8h_a8e8ccb957397b2a568e8a86d29a6ce4a}{p4est\+\_\+mesh\+\_\+new\+\_\+ext}} or \mbox{\hyperlink{p4est__mesh_8h_a663b5101edeb5674d66a7c3692d6661a}{p4est\+\_\+mesh\+\_\+new\+\_\+params}}.

The quad\+\_\+to\+\_\+quad list stores one value for each local quadrant\textquotesingle{}s face. This value is in 0..local\+\_\+num\+\_\+quadrants-\/1 for local quadrants, or in local\+\_\+num\+\_\+quadrants + (0..ghost\+\_\+num\+\_\+quadrants-\/1) for ghost quadrants.

The quad\+\_\+to\+\_\+face list has equally many entries that are either\+:
\begin{DoxyEnumerate}
\item A value of v = 0..7 indicates one same-\/size neighbor. This value is decoded as v = r $\ast$ 4 + nf, where nf = 0..3 is the neighbor\textquotesingle{}s connecting face number and r = 0..1 is the relative orientation of the neighbor\textquotesingle{}s face; see \mbox{\hyperlink{p4est__connectivity_8h}{p4est\+\_\+connectivity.\+h}}.
\item A value of v = 8..23 indicates a double-\/size neighbor. This value is decoded as v = 8 + h $\ast$ 8 + r $\ast$ 4 + nf, where r and nf are as above and h = 0..1 is the number of the subface. h designates the subface of the large neighbor that the quadrant touches (this is the same as the large neighbor\textquotesingle{}s face corner).
\item A value of v = -\/8..-\/1 indicates two half-\/size neighbors. In this case the corresponding quad\+\_\+to\+\_\+quad index points into the quad\+\_\+to\+\_\+half array that stores two quadrant numbers per index, and the orientation of the smaller faces follows from 8 + v. The entries of quad\+\_\+to\+\_\+half encode between local and ghost quadrant in the same way as the quad\+\_\+to\+\_\+quad values described above. The small neighbors in quad\+\_\+to\+\_\+half are stored in the sequence of the face corners of this, i.\+e., the large quadrant.
\end{DoxyEnumerate}

A quadrant on the boundary of the forest sees itself and its face number.

The quad\+\_\+to\+\_\+corner list stores corner neighbors that are not face neighbors. On the inside of a tree, there is precisely one such neighbor per corner. In this case, its index is encoded as described above for quad\+\_\+to\+\_\+quad. The neighbor\textquotesingle{}s matching corner number is always diagonally opposite, that is, corner number $^\wedge$ 3.

On the inside of an inter-\/tree face, we have precisely one corner neighbor. If a corner is an inter-\/tree corner, then the number of corner neighbors may be any non-\/negative number. In both cases, the quad\+\_\+to\+\_\+corner value is in local\+\_\+num\+\_\+quadrants + local\+\_\+num\+\_\+ghosts + \mbox{[}0 .. local\+\_\+num\+\_\+corners -\/ 1\mbox{]}. After subtracting the number of local and ghost quadrants, it indexes into corner\+\_\+offset, which encodes a group of corner neighbors. Each group contains the quadrant numbers encoded as usual for quad\+\_\+to\+\_\+quad in corner\+\_\+quad, and the corner number from the neighbor as corner\+\_\+corner.

Corners with no diagonal neighbor at all are assigned the value -\/3. This only happens on the domain boundary, which is necessarily a tree boundary. Corner-\/neighbors for hanging nodes are assigned the value -\/1.

The params struct describes the parameters the mesh was created with. For full control over the parameters, use \mbox{\hyperlink{p8est__mesh_8h_adaa1defdb41a2510def4310bc85b97a2}{p8est\+\_\+mesh\+\_\+new\+\_\+params}} for mesh creation.
