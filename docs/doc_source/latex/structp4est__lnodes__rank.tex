\doxysubsection{Detailed Description}
The structure stored in the sharers array. 

shared\+\_\+nodes is a sorted array of p4est\+\_\+locidx\+\_\+t that indexes into local nodes. The shared\+\_\+nodes array has a contiguous (or empty) section of nodes owned by the current rank. shared\+\_\+mine\+\_\+offset and shared\+\_\+mine\+\_\+count identify this section by indexing the shared\+\_\+nodes array, not the local nodes array. owned\+\_\+offset and owned\+\_\+count define the section of local nodes that is owned by the listed rank (the section may be empty). For the current process these coincide with those in p4est\+\_\+lnodes\+\_\+t.
