\doxysubsection{Detailed Description}
Provide functions to serialize/deserialize a forest. 

Some are used as building blocks for \mbox{\hyperlink{p4est_8h_a9296defed7471c1a85d6dd2cc3d62f30}{p4est\+\_\+load}} and \mbox{\hyperlink{p4est_8h_a43227500492e202775123cfca6772b1d}{p4est\+\_\+save}}. Others allow for saving and loading user-\/defined data to a parallel file.

Furthermore, this module provides functions to write and read general data files associated with a \mbox{\hyperlink{structp4est}{p4est}}.
