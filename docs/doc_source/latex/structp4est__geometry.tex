\doxysubsection{Detailed Description}
Encapsulates a custom transformation from tree-\/local coordinates to user defined physical space. 

Used in \mbox{\hyperlink{p4est__vtk_8h}{p4est\+\_\+vtk.\+h}} to write global-\/coordinate meshes.

Some internal \mbox{\hyperlink{structp4est}{p4est}} functions assume that $\ast$user points to a \mbox{\hyperlink{structp4est__connectivity}{p4est\+\_\+connectivity}}. However, in general it can be used as the user wishes.

This structure can be filled or allocated by the user. \mbox{\hyperlink{structp4est}{p4est}} will never change its contents. \begin{Desc}
