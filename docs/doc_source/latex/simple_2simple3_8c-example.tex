\hypertarget{simple_2simple3_8c-example}{}\doxysection{simple/simple3.\+c}
This 3D application generates, refines, and adjusts a mesh set on the command line.\+The resulting VTK files visually present each stage of the mesh modification procedure.

Usage\+: \begin{quote}
{\ttfamily p8est\+\_\+simple $<$configuration$>$ $<$level$>$} \end{quote}
possible configurations\+:
\begin{DoxyItemize}
\item unit The unit cube.
\item brick The brick connectivity.
\item periodic The unit cube with all-\/periodic boundary conditions.
\item rotwrap The unit cube with various self-\/periodic b.\+c.
\item twocubes Two connected cubes.
\item twowrap Two cubes with periodically identified far ends.
\item rotcubes A collection of six connected rotated cubes.
\item shell A 24-\/tree discretization of a hollow sphere.
\item sphere A 13-\/tree discretization of a solid sphere.
\end{DoxyItemize}
