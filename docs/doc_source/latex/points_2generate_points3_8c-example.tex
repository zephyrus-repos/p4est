\hypertarget{points_2generate_points3_8c-example}{}\doxysection{points/generate\+\_\+points3.\+c}
3D auxiliary program to generate a file of points in parallel.\+It uses the MPI I/O functionality of libsc to create one large file. The file is written to in parallel and using partitioned file access.

The file contains first a binary integer \mbox{\hyperlink{p4est__base_8h_af4d787f9b2520af0cfe9a10b89235749}{p4est\+\_\+gloidx\+\_\+t}} storing the global number of points and then the list of point coordinates as 3-\/tuples of binary type double.

The usage of the program is \begin{DoxyVerb}p8est_points_generate <configuration> <globalnumpoints> <prefix>
\end{DoxyVerb}
 where configuration is one of


\begin{DoxyItemize}
\item {\ttfamily unit} The unit cube,
\item {\ttfamily brick} An example brick connectivity using configuration (2,3,4) as the number of trees per direction.
\item {\ttfamily periodic} The unit cube with all-\/periodic boundary conditions.
\item {\ttfamily rotwrap} The unit cube with various self-\/periodic b.\+c.
\item {\ttfamily twocubes} Two connected cubes.
\item {\ttfamily rotcubes} A collection of six connected rotated cubes.
\end{DoxyItemize}
