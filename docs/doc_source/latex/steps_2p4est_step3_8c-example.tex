\hypertarget{steps_2p4est_step3_8c-example}{}\doxysection{steps/p4est\+\_\+step3.\+c}
This 2D example program (3D counterpart\+: \mbox{\hyperlink{steps_2p8est_step3_8c-example}{steps/p8est\+\_\+step3.\+c}}) uses \mbox{\hyperlink{structp4est}{p4est}} to solve a simple advection problem.\+It is numerically very simple, and intended to demonstrate several methods of interacting with the \mbox{\hyperlink{structp4est}{p4est}} data after it has been refined and partitioned. It demonstrates the construction of \mbox{\hyperlink{ghost}{ghost}} layers (cf. also \mbox{\hyperlink{p4est__ghost_8h}{p4est\+\_\+ghost.\+h}}) and communication of ghost-\/layer data, and it demonstrates interacting with the quadrants and quadrant boundaries through the \mbox{\hyperlink{p4est__iterate_8h_aca75de06c7e9f039fa3be925a6ae87b4}{p4est\+\_\+iterate}} routine (cf. \mbox{\hyperlink{p4est__iterate_8h}{p4est\+\_\+iterate.\+h}}).

Usage\+: \begin{quote}
{\ttfamily p4est\+\_\+step3} \end{quote}
