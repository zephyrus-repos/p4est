\hypertarget{particles_2particles3_8c-example}{}\doxysection{particles/particles3.\+c}
The 3D version of the particle tracking demo compiles from the same code as the 2D example \mbox{\hyperlink{particles_2particles2_8c-example}{particles/particles2.\+c}} with minimal redefinitions. In this sense, the code is mostly dimension independent.
