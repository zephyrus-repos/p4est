\doxysubsection{Detailed Description}
Information about one side of a face in the forest. 

If a {\itshape quad} is local ({\itshape is\+\_\+ghost} is false), then its {\itshape quadid} indexes the tree\textquotesingle{}s quadrant array; otherwise, it indexes the ghosts array. If the face is hanging, then the quadrants are listed in z-\/order. If a quadrant should be present, but it is not included in the ghost layer, then quad = NULL, is\+\_\+ghost is true, and quadid = -\/1. \begin{Desc}
