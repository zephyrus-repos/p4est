\doxysubsection{Detailed Description}
Information about one side of a corner in the forest. 

If a {\itshape quad} is local ({\itshape is\+\_\+ghost} is false), then its {\itshape quadid} indexes the tree\textquotesingle{}s quadrant array; otherwise, it indexes the ghosts array. If a quadrant should be present, but it is not included in the ghost layer, then quad = NULL, is\+\_\+ghost is true, and quadid = -\/1.

the {\itshape faces} field provides some additional information about the local topology\+: if side\mbox{[}i\mbox{]}-\/$>$faces\mbox{[}j\mbox{]} == side\mbox{[}k\mbox{]}-\/$>$faces\mbox{[}l\mbox{]}, this indicates that there is a common face between these two sides of the corner.
