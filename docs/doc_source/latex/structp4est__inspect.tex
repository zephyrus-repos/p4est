\doxysubsection{Detailed Description}
Data pertaining to selecting, inspecting, and profiling algorithms. 

A pointer to this structure is hooked into the \mbox{\hyperlink{structp4est}{p4est}} main structure.

The balance\+\_\+ranges and balance\+\_\+notify$\ast$ times are collected whenever an inspect structure is present in \mbox{\hyperlink{structp4est}{p4est}}. \begin{Desc}
