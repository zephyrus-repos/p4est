\hypertarget{points_2generate_points2_8c-example}{}\doxysection{points/generate\+\_\+points2.\+c}
Auxiliary program (3D counterpart\+: \mbox{\hyperlink{points_2generate_points3_8c-example}{points/generate\+\_\+points3.\+c}}) to generate a file of points in parallel.\+It uses the MPI I/O functionality of libsc to create one large file. The file is written to in parallel and using partitioned file access.

The file contains first a binary integer \mbox{\hyperlink{p4est__base_8h_af4d787f9b2520af0cfe9a10b89235749}{p4est\+\_\+gloidx\+\_\+t}} storing the global number of points and then the list of point coordinates as 3-\/tuples of binary type double.

The usage of the program is \begin{DoxyVerb}p4est_points_generate <configuration> <globalnumpoints> <prefix>
\end{DoxyVerb}
 where configuration is one of


\begin{DoxyItemize}
\item {\ttfamily unit} The 2D unit square,
\item {\ttfamily brick} A 2x3 grid of squares,
\item {\ttfamily three} Three squares meeting at a non-\/planary angle,
\item {\ttfamily moebius} A five-\/square moebius strip embedded in 3D space,
\item {\ttfamily star} A star composed of six rhomboids,
\item {\ttfamily periodic} The all-\/periodic unit square
\end{DoxyItemize}

and prefix is an output basename or filename to which we append {\ttfamily .pts}.
