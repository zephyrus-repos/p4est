\hypertarget{timings_2timings3_8c-example}{}\doxysection{timings/timings3.\+c}
This 3D example program calls \mbox{\hyperlink{structp4est}{p4est}}\textquotesingle{}s core routines.\+The example\textquotesingle{}s purpose is to measure the runtime of \mbox{\hyperlink{structp4est}{p4est}}\textquotesingle{}s core routines.

Usage\+: \begin{quote}
{\ttfamily p8est\+\_\+timings $<$configuration$>$ $<$level$>$} \end{quote}
possible configurations\+:
\begin{DoxyItemize}
\item {\ttfamily unit} Refinement on the unit cube.
\item {\ttfamily periodic} Refinement on the unit cube with all-\/periodic b.\+c.
\item {\ttfamily rotwrap} Refinement on the unit cube with weird periodic b.\+c.
\item {\ttfamily twocubes} Refinement on a forest with two trees.
\item {\ttfamily rotcubes} Refinement on a forest with six rotated trees.
\item {\ttfamily shell} Refinement on a 24-\/tree spherical shell..
\end{DoxyItemize}
