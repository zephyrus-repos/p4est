\hypertarget{timings_2timings2_8c-example}{}\doxysection{timings/timings2.\+c}
This 2D example program (3D counterpart\+: \mbox{\hyperlink{timings_2timings3_8c-example}{timings/timings3.\+c}}) calls \mbox{\hyperlink{structp4est}{p4est}}\textquotesingle{}s core routines.\+The example\textquotesingle{}s purpose is to measure the runtime of \mbox{\hyperlink{structp4est}{p4est}}\textquotesingle{}s core routines.

Usage\+: \begin{quote}
{\ttfamily p4est\+\_\+timings $<$configuration$>$ $<$level$>$} \end{quote}
possible configurations\+:
\begin{DoxyItemize}
\item {\ttfamily unit} Refinement on the unit square.
\item {\ttfamily periodic} Refinement on the unit square with periodic b.\+c.
\item {\ttfamily three} Refinement on a forest with three trees.
\item {\ttfamily moebius} Refinement on a 5-\/tree Moebius band.
\item {\ttfamily star} Refinement on a 6-\/tree star shaped domain.
\end{DoxyItemize}
