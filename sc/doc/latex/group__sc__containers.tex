\doxysubsection{Detailed Description}
The library provides dynamic containers such as lists, arrays, and hash tables. 

The \mbox{\hyperlink{structsc__array}{sc\+\_\+array}} structure serves as lightweight resizable array. Based on this array, we implement the \mbox{\hyperlink{structsc__hash}{sc\+\_\+hash}} table and the \mbox{\hyperlink{structsc__hash__array}{sc\+\_\+hash\+\_\+array}}. We also add a string implementation in \mbox{\hyperlink{sc__string_8h}{sc\+\_\+string.\+h}}.
