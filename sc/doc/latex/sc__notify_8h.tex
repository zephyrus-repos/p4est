\doxysubsection{Detailed Description}
We provide various algorithms to invert the communication pattern. 

The task at hand is\+: given an individual set of receiver ranks for each process in a sender role, compute efficiently for the receiver role of each rank the set of senders to it.

This file implements two approaches that solve the problem scalably.


\begin{DoxyEnumerate}
\item The first and original historic one offers the choice between a binary tree recursion, an n-\/ary tree recursion, optionally with payload data, and an allgather version. The n-\/ary tree version contains the binary one as a special case. It is called \mbox{\hyperlink{sc__notify_8h_aa95b3d2205c9f473b453650bb2d15dba}{sc\+\_\+notify\+\_\+nary}} and can be configured by the global variables
\begin{DoxyItemize}
\item \mbox{\hyperlink{sc__notify_8h_a4db60160a1f739001fdf837d2dcfd7a8}{sc\+\_\+notify\+\_\+nary\+\_\+ntop\+\_\+default}}; \#children of the root tree node,
\item \mbox{\hyperlink{sc__notify_8h_a86f17f170ffdcef7a73f16ef55173442}{sc\+\_\+notify\+\_\+nary\+\_\+nint\+\_\+default}}; \#children of intermediate nodes,
\item \mbox{\hyperlink{sc__notify_8h_ac7da95a48e6b49de5ca259cd82a31308}{sc\+\_\+notify\+\_\+nary\+\_\+nbot\+\_\+default}}; \#siblings of each leaf node.
\end{DoxyItemize}

Thus it can be tailored to match for example distributed NUMA architectures. The default for each variable is a conservative 2 to choose a binary tree.

Another addition to the family is \mbox{\hyperlink{sc__notify_8h_a68ba53034e92a90d2af1cb80228439e5}{sc\+\_\+notify\+\_\+ext}} for the best known default, which is currently the PEX algorithm.
\item The more recent and general variant allows to choose between practically all currently known algorithms, enumerated by \mbox{\hyperlink{sc__notify_8h_a3efd21dcb5fd8499a9f199141c55abf8}{sc\+\_\+notify\+\_\+type\+\_\+t}}. This is managed by first creating a configuration object \mbox{\hyperlink{sc__notify_8h_af45e0174f6d9a3c1a108780116e1e5f8}{sc\+\_\+notify\+\_\+t}}, setting its type and further parameters, and passing it into the general \mbox{\hyperlink{sc__notify_8h_a1bb637268a14b63422eeef5b0acdb5de}{sc\+\_\+notify\+\_\+payload}} or \mbox{\hyperlink{sc__notify_8h_a1d26f916496dcb8abca383a9f5b64bd9}{sc\+\_\+notify\+\_\+payloadv}} functions. 
\end{DoxyEnumerate}
