\doxysubsection{Detailed Description}
The log level is a number designating the priority of a log action. 

Log levels serve both to indicate the priority of a message and as a filter passed to functions to determine which priorities to log.

The priorities \mbox{\hyperlink{group__sc__logprios_ga430c0bc54b14a41db7c65a0005891295}{SC\+\_\+\+LP\+\_\+\+TRACE}} to \mbox{\hyperlink{group__sc__logprios_gad086ba973c03342b2ac02390d5e0c1f1}{SC\+\_\+\+LP\+\_\+\+VERBOSE}} may be used profusely and are appropriate when all parallel processes contribute low-\/priority, informative log messages.

\mbox{\hyperlink{group__sc__logprios_ga46e69bd79ab3e27b9a7df896c0459cbb}{SC\+\_\+\+LP\+\_\+\+INFO}} and above should not clutter the output of large parallel runs. \mbox{\hyperlink{group__sc__logprios_ga3e5e906eb2a18a1149ff90d817ed08b1}{SC\+\_\+\+LP\+\_\+\+STATISTICS}} is suggested for important measurements. \mbox{\hyperlink{group__sc__logprios_gaa6ad8d10240f12d56bb3569639edce12}{SC\+\_\+\+LP\+\_\+\+PRODUCTION}} is meant for rudimentary information on the program flow.

\mbox{\hyperlink{group__sc__logprios_gab987f887ad374d3c61c328918e4f861c}{SC\+\_\+\+LP\+\_\+\+ESSENTIAL}} can be used for one-\/time messages, say at program startup to communicate program version or licence information.

\mbox{\hyperlink{group__sc__logprios_ga4f982c3e4f449c6fefdc14458335ec19}{SC\+\_\+\+LP\+\_\+\+ERROR}} shall never be used during clean operation. Thus, it can be used to indicate abnormal behavior of the program and will not disturb the silent appearance of a clean run. Recommended for those who generally prefer to see absolutely no output from the libraries they use.
