\doxysubsection{Detailed Description}
A data container to create memory items of the same size. 

Allocations are bundled so it\textquotesingle{}s fast for small memory sizes. The items created will remain valid until the container is destroyed. There is no option to return an item to the container. See \mbox{\hyperlink{sc__containers_8h_a9d4ef6fe706382d2d67a66fba72d0bf4}{sc\+\_\+mempool\+\_\+t}} for that purpose.
