\doxysubsection{Detailed Description}
The \mbox{\hyperlink{structsc__array}{sc\+\_\+array}} object provides a dynamic array of equal-\/size elements. 

Elements are accessed by their 0-\/based index. Their address may change. The number of elements (== elem\+\_\+count) of the array can be changed by \mbox{\hyperlink{sc__containers_8h_a584d8488f231972c68d44eb6239c9cd8}{sc\+\_\+array\+\_\+resize}} and \mbox{\hyperlink{sc__containers_8h_a30ec6fe1bb8a06481c6677e63efc76ec}{sc\+\_\+array\+\_\+rewind}}. Elements can be sorted with \mbox{\hyperlink{sc__containers_8h_a750f7188a30c8c2756c77d70967b0caf}{sc\+\_\+array\+\_\+sort}}. If the array is sorted, it can be searched with \mbox{\hyperlink{sc__containers_8h_aa0759d2b44ed0aadb8c325f7bd5f5449}{sc\+\_\+array\+\_\+bsearch}}. A priority queue is implemented with pqueue\+\_\+add and pqueue\+\_\+pop (untested).
