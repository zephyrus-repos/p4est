The general workflow for the scda format provided by \mbox{\hyperlink{sc__scda_8h}{sc\+\_\+scda.\+h}}

All workflows start with \mbox{\hyperlink{sc__scda_8h_a14638ad9e17b15a3e449e4e10fee507c}{sc\+\_\+scda\+\_\+fopen\+\_\+write}} or \mbox{\hyperlink{sc__scda_8h_ac336fd36bcbff9f64fd23f63028b4f89}{sc\+\_\+scda\+\_\+fopen\+\_\+read}} that creates a file context \mbox{\hyperlink{sc__scda_8h_acfad0eccefabd5d5371c69363410bec7}{sc\+\_\+scda\+\_\+fcontext\+\_\+t}} that never moves backwards.

Then the user may call any combination of functions out of\+:


\begin{DoxyItemize}
\item \mbox{\hyperlink{sc__scda_8h_a82eec2df05911d66d8ce1673343862b7}{sc\+\_\+scda\+\_\+fwrite\+\_\+inline}},
\item \mbox{\hyperlink{sc__scda_8h_a1f2290fa5a5f963ab29290ff3fe7d506}{sc\+\_\+scda\+\_\+fwrite\+\_\+block}},
\item \mbox{\hyperlink{sc__scda_8h_ad645fba87e9fac212c635f4c91cecec9}{sc\+\_\+scda\+\_\+fwrite\+\_\+array}} and
\item \mbox{\hyperlink{sc__scda_8h_a82171bb305fc39e606fa02f5948d27b0}{sc\+\_\+scda\+\_\+fwrite\+\_\+varray}},
\end{DoxyItemize}

for a context obtained from \mbox{\hyperlink{sc__scda_8h_a14638ad9e17b15a3e449e4e10fee507c}{sc\+\_\+scda\+\_\+fopen\+\_\+write}}.

Alternatively, after using \mbox{\hyperlink{sc__scda_8h_ac336fd36bcbff9f64fd23f63028b4f89}{sc\+\_\+scda\+\_\+fopen\+\_\+read}} the user must call \mbox{\hyperlink{sc__scda_8h_aa7a7eddf6cf00319260e93bac577aab8}{sc\+\_\+scda\+\_\+fread\+\_\+section\+\_\+header}} that examines the current file section and then call accordingly to the retrieved file section type one of


\begin{DoxyItemize}
\item \mbox{\hyperlink{sc__scda_8h_a0f83f0c77e5a631799421fb77224c384}{sc\+\_\+scda\+\_\+fread\+\_\+inline\+\_\+data}},
\item \mbox{\hyperlink{sc__scda_8h_a171d5c3128d1aeb2c629ec209d154a72}{sc\+\_\+scda\+\_\+fread\+\_\+block\+\_\+data}},
\item \mbox{\hyperlink{sc__scda_8h_a4b347bcb7646f1ee1e7be1156e4ee51f}{sc\+\_\+scda\+\_\+fread\+\_\+array\+\_\+data}},
\item \mbox{\hyperlink{sc__scda_8h_a23a855a2ce1a3dcb18c15ef50f6a909a}{sc\+\_\+scda\+\_\+fread\+\_\+varray\+\_\+sizes}} and
\item \mbox{\hyperlink{sc__scda_8h_a16305c56eb58f12826c276584f888a1a}{sc\+\_\+scda\+\_\+fread\+\_\+varray\+\_\+data}}.
\end{DoxyItemize}

Finally, the file context is collectively closed and deallocated by \mbox{\hyperlink{sc__scda_8h_ad547d1af82bca7b524b39d363fa8a903}{sc\+\_\+scda\+\_\+fclose}}.

All above mentioned sc\+\_\+scda functions are collective and output an error code (cf. \mbox{\hyperlink{sc__scda_8h_a3613f101cd3d474bae0609313c45a135}{sc\+\_\+scda\+\_\+ferror\+\_\+t}}) that can be translated by \mbox{\hyperlink{sc__scda_8h_a1191840fde06a11537122a5701a75eef}{sc\+\_\+scda\+\_\+ferror\+\_\+string}}.

For more details and the option for encoding metadata and data see the functions in \mbox{\hyperlink{sc__scda_8h}{sc\+\_\+scda.\+h}}.
