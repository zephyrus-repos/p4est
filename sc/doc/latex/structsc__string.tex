\doxysubsection{Detailed Description}
This is a simple type for growing a string by printf-\/like commands. 

It is public so it can be declared on the stack to avoid malloc and free. This means that the length of the string is limited to \mbox{\hyperlink{sc__string_8h_ab7176b57256b52794d45e29ed89d0a24}{SC\+\_\+\+STRING\+\_\+\+SIZE}} -\/ 1. The current string can be accessed by \mbox{\hyperlink{sc__string_8h_a5358b5e854c5111c250e6b90f10ea9b2}{sc\+\_\+string\+\_\+get\+\_\+content}}. This is really an opaque object\+: its members shall not be accessed directly.
