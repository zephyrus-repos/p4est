\doxysubsection{Detailed Description}
The \mbox{\hyperlink{structsc__mempool}{sc\+\_\+mempool}} object provides a large pool of equal-\/size elements. 

The pool grows dynamically for element allocation. Elements are referenced by their address which never changes. Elements can be freed (that is, returned to the pool) and are transparently reused. If the zero\+\_\+and\+\_\+persist option is selected, new elements are initialized to all zeros on creation, and the contents of an element are not touched between freeing and re-\/returning it.
