\doxysubsection{Detailed Description}
We provide MPI replacement data types for configuring without MPI. 

Included from both \mbox{\hyperlink{sc__mpi_8h}{sc\+\_\+mpi.\+h}} and the future {\ttfamily sc3\+\_\+mpi.\+h}.

We wrap the MPI 3 window object. 

With MPI 3 windows available, the functionality is unchanged. Without MPI 3 available, it is primitive but allows basic use.

When created with a communicator size of one, or when {\ttfamily configure} does not define SC\+\_\+\+ENABLE\+\_\+\+MPIWINSHARED, we use the wrapper and do not go through MPI. When shared windows are not supported and the communicator has size $>$ 1, the wrapper cannot query or lock and unlock the window of remote ranks. Any such attempt will result in a fatal error returned.
